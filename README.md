# SoquShield

Post-quantum mobile wallet by [Soqucoin Labs Inc.](https://soqu.org)

## Features

- 🔐 **FIPS 204 ML-DSA-44** key generation (quantum-resistant)
- 🏠 **Bech32m** native addresses (witness v1)
- 📝 **24-word BIP-39** recovery phrase
- 🌉 **pSOQ ↔ SOQ** bridge interface
- ⚡ **Stagenet live** — connected to Soqucoin stagenet
- 🍎 iOS & Android support
