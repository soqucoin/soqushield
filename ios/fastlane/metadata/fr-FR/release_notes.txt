Cette version ajoute deux façons de renseigner un destinataire. Scannez le code QR d'une adresse avec l'appareil photo. Le scan lit l'adresse et rien d'autre. Tenez un carnet d'adresses sur l'appareil. Enregistrez un destinataire sous le nom de votre choix, choisissez-le sur l'écran Send et enregistrez un destinataire après un envoi. Une adresse est vérifiée avant d'entrer dans le carnet. Wipe wallet vide le carnet.
